# Personal Portfolio Website — Assignment 1

A responsive multi-page personal portfolio developed with semantic HTML5 and modular CSS3. 
The site showcases a landing home page, personal background, previous projects, and a structured contact form, tailored across mobile, tablet, and desktop screens.
